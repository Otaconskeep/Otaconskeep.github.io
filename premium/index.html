Premium // Retired

Premium is gone. Expansion is free.

Otaconskeep used to run Expansion and Keep Desk install access behind a $1 licensed seat, issued by hand on Buy Me a Coffee. That gate is retired. There is no license key, no access name, no PIN, and no seat limit anymore, on any product.

Go to Expansion → Go to Keep Desk → Support the build (optional)

What changed

No more gate

  • Expansion installs the same way Otacon Lite does, no seat required. See /expansion/.
  • Keep Desk ships from a public repository. See /keepdesk/.
  • The old access name / password / PIN gate on this page has been removed. Old credentials no longer do anything, because nothing is locked anymore.

Thank you

Founding supporters

Josh Block and Cris Cristo supported this build early, back when a $1 seat was how Expansion and Keep Desk install access was funded. That system is gone, but the thanks stand. If you want to support the project the same way they did, it now lives at /donate/, entirely optional.
