Architecture

Extension → backend → GPU pipeline

Firefox (contentScript.js)→ Flask backend (app-stream.py)→ Denoise (FFDNet)→ Colorize (GAN)→ Optional 4x upscale→ Content-hash cache

Concurrency is 1 by default: one page colorizes at a time, queued, so the GPU stays available for other work. A two-tier cache keyed by image content hash and processing options means switching color presets on an already-read page reuses the raw GPU output instead of a full re-run.

Hardware Support

Automatic GPU detection & runtime selection

The installer reads your GPU name and driver's max CUDA version directly from nvidia-smi, then picks the matching PyTorch wheel. No manual CUDA version guessing.

GPU generationCompute capabilityPyTorch build
RTX 50-series (Blackwell)sm_120cu128
RTX 40-series (Ada)sm_89cu121 / cu126
RTX 30-series (Ampere)sm_86cu118

Verified with a real GPU inference pass (matmul + cuDNN convolution kernels), not just torch.cuda.is_available(). That call can return True while still lacking compiled kernels for your specific architecture.

Install // Dual method

Windows 10/11: one-click or baby steps

Method 1: download one file and double-click it from Downloads. Method 2: prerequisites + copy-paste one line + clickable error fixes. Do not type only the filename into Command Prompt — that is why 'install_ai9.bat' is not recognized shows up.

Download AI9 Setup

Saves as AI9-Setup.bat. Open Downloads → double-click. If Windows SmartScreen appears, choose More info → Run anyway. The launcher fetches the rest automatically and installs Git Bash if needed.

Requires an NVIDIA GPU with a current Game Ready / Studio driver. No WSL, no Linux VM, no ZIP extract required for the normal path.

  1. Download AI9 Setup from this page

    Use the button above (or the homepage install panel). Prefer this site’s /downloads/ button, don’t Save-As from raw GitHub links.

  2. Double-click AI9-Setup.bat in Downloads

    Not Command Prompt. Not PowerShell. Finder/Explorer double-click. The window stays open and walks the install.

  3. Wait for it to finish

    Installs Python 3.12, Git, and Firefox if missing (via winget); detects your GPU and installs the matching PyTorch build; downloads and verifies the AI model weights; runs a real GPU inference test; registers a Windows background task so the server auto-starts and restarts itself on crash.

  4. Load the Firefox extension (the one manual step)

    Firefox requires a human click for unsigned add-ons. No installer can do this part. Go to about:debugging#/runtime/this-firefox → Load Temporary Add-on → select extension/manifest.json from the install folder (default C:\opt\manga-colorizer\extension\). This needs repeating after every full Firefox restart.

winget may trigger a Windows UAC prompt when installing missing Git, Python, or Firefox. The installer itself does not need to run elevated/as administrator.

Step 2b · Load the Firefox extension (required once)

  1. Open Firefox and go to about:debugging#/runtime/this-firefox
  2. Click Load Temporary Add-on…
  3. Select C:\opt\manga-colorizer\extension\manifest.json (default path).
  4. After a full Firefox restart you must load it again — that is a Firefox unsigned-addon limit.

When the server is up: https://127.0.0.1:5000/ (self-signed cert warning is normal once).

If something looks wrong Click the message you see

'AI9-Setup.bat' is not recognized
  1. You typed the filename into CMD without being in the Downloads folder.
  2. Fix: use the Method 1 download button and double-click the file, or use the full one-liner above (it downloads and starts for you).
SmartScreen / “Windows protected your PC”
  1. Click More info → Run anyway.
  2. Unsigned batch scripts often get this the first time.
Window flashes and closes instantly
  1. Git Bash may be missing and winget failed. Install App Installer, then rerun Setup.
  2. Or install Git for Windows yourself, then double-click Setup again.
nvidia-smi / CUDA / GPU test failed
  1. Update the NVIDIA driver, reboot, run nvidia-smi again.
  2. Rerun Setup — it is safe to run twice; it skips finished steps.
Self-signed certificate warning in the browser
  1. Expected for local https://127.0.0.1:5000/.
  2. Click Advanced → proceed/accept once for this address.
Extension gone after Firefox restart
  1. Unsigned temporary add-ons do not persist. Reload via about:debugging as in Step 2b.

Known limitations (from the repository's own troubleshooting notes):

  • The Firefox extension is loaded as an unsigned temporary add-on. It does not persist across a full Firefox restart and needs reloading.
  • A canvas-based reader can be repainted with zero DOM mutation trace, so those pages use a narrow, low-frequency fingerprint poll instead of pure event-driven detection: a deliberate, disclosed tradeoff.
  • The backend serves over a self-signed certificate; browsers show a one-time trust warning per origin.
