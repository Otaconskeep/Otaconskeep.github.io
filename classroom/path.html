🛤️ Windows WSL2 or Linux?

This course supports two paths for running Docker and your homelab services:

  • Windows Path: Windows 10/11 + WSL2 (Ubuntu) + Docker Desktop
  • Linux Path: Ubuntu/Debian bare metal or VM + Docker Engine
💡 Good news: Both paths share ~80% of the same course content. You'll only see OS-specific tabs when install steps, file paths, or permissions differ.

🪟 Windows Path

Best for: Windows 10/11 desktop or laptop users who want to keep their existing OS

You will use:

  • Windows Subsystem for Linux 2 (WSL2)
  • Ubuntu 22.04 inside WSL2
  • Docker Desktop for Windows
  • Windows file paths (\\wsl$\Ubuntu\data)

Prerequisites:

  • Windows 10 version 2004+ or Windows 11
  • 8GB+ RAM (16GB recommended)
  • Virtualization enabled in BIOS
Start Windows Path →

🐧 Linux Path

Best for: Dedicated Linux server, VM, or native Linux desktop users

You will use:

  • Ubuntu 22.04 / 24.04 or Debian 12
  • Docker Engine (installed via apt)
  • Standard Linux file paths (/data)
  • systemd service management

Prerequisites:

  • Fresh Ubuntu/Debian install or VM
  • 4GB+ RAM (8GB+ recommended)
  • SSH access if running headless

🔄 Can I Switch Paths Later?

Yes! The concepts are identical. If you start on Windows and later move to a dedicated Linux server, you'll only need to adjust:

  • File paths in your docker-compose.yml files
  • User/group permissions (UID/GID)
  • Docker installation method (Desktop vs Engine)

📝 What About Proxmox / NAS?

This course will note where Proxmox VMs and NAS storage fit into the architecture, but we focus on the Docker + Home Assistant core first.

Advanced paths covered later:

  • Proxmox: Running Docker in an LXC container or VM (Unit 1 mentions concepts)
  • NAS storage: SMB/NFS mounts for media libraries (mentioned in Unit 2)
  • Dedicated GPU: Hardware transcoding for Plex/Jellyfin (mentioned in Unit 2)

For now, pick Windows (WSL2) or Linux (bare metal/VM) and start learning Docker.
