🎓 What Is the Final Exam?

This is not a written test. The final exam is a complete system verification matrix that proves your homelab works end-to-end.

You will execute a full workflow:

  1. Request media → Add a TV show in Sonarr and a movie in Radarr
  2. Verify automation → Prowlarr searches indexers, downloads start automatically
  3. Watch media → Episode/movie appears in Plex or Jellyfin
  4. Control home → Turn a light on/off via Home Assistant automation
  5. Use voice → Ask your local voice assistant to report sensor status
💡 Capstone requirement: Your voice assistant must work with your internet connection physically disconnected. This proves it's 100% local.

🚀 Capstone Workflow Test

Execute this complete workflow to prove your system works end-to-end:

Request New Media

Open Sonarr web UI → Add a new TV series (e.g., "The Expanse") → Monitor first episode

Open Radarr web UI → Add a new movie (e.g., "Interstellar") → Monitor

Verify Automation Kicks In

Within 5 minutes, check Activity in Sonarr/Radarr → Search should show results from Prowlarr

Download should appear in qBittorrent or SABnzbd download queue

Wait for Import

After download completes, Sonarr/Radarr should automatically import to /data/media

Check file is hardlinked (still seeding in torrent client AND visible in media folder)

Watch in Plex/Jellyfin

Open Plex or Jellyfin web UI

Navigate to TV Shows or Movies library → Find imported content → Start playback

Success: Video plays without errors

Test Home Assistant Automation

Trigger your automation manually from HA Developer Tools → Services

OR wait for real trigger (e.g., door opens at night → light turns on)

Success: Action executes as expected

Use Voice Assistant

Stand near your microphone/satellite device

Say: "Ok Nabu, what is the temperature in the living room?"

Success: Assistant responds with correct sensor value

Internet-Disconnected Capstone Test

Physically disconnect your server from the internet (unplug ethernet or disable Wi-Fi)

Retry voice command: "Ok Nabu, turn off the bedroom light"

Success: Assistant responds and executes action WITHOUT internet

This proves your system is 100% local.

❌ Troubleshooting the Final Exam

Problem: Sonarr/Radarr not finding releases

→ Check Prowlarr indexers are online and synced
→ Verify API keys match between Prowlarr ↔ Sonarr/Radarr
→ Test manual search in Prowlarr web UI first

Problem: Downloads not importing to media library

→ Verify /data paths are consistent across containers
→ Check UID/GID permissions in docker-compose.yml
→ Review Sonarr/Radarr logs for "import failed" messages

Problem: Plex not seeing new media

→ Force library scan in Plex web UI
→ Check Plex has correct path to /data/media
→ Verify file permissions (Plex user can read files)

Problem: Home Assistant automation not firing

→ Check trigger condition is actually met (test with Developer Tools)
→ Review automation trace in HA UI
→ Simplify: remove conditions temporarily to isolate problem

Problem: Voice assistant not responding

→ Test Whisper + Piper separately in HA Assist pipeline (push-to-talk mode)
→ Check Wyoming service logs (docker logs whisper, docker logs piper)
→ Verify wake word is enabled and microphone input is working
→ Test with known wake word "ok nabu" before custom words

Problem: Voice works WITH internet but not WITHOUT

→ Check HA Assist pipeline uses local STT/TTS (not Google/Azure)
→ Verify Whisper/Piper containers are running locally, not cloud APIs
→ Review Home Assistant logs when internet is disconnected
