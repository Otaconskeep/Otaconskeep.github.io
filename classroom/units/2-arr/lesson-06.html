Lesson 2.2: TRaSH Fundamentals — Quality Profiles & Custom Formats

INTERMEDIATE

📚 What You Are Learning

One concept: How TRaSH Guides Custom Formats (CFs) score releases to automatically select the best quality.

You'll learn to import CF scoring that prefers DV/HDR, avoids hardcoded subs, and rewards proper release groups.

✅ You Should Already Have

  • Prowlarr and Sonarr running (from Lesson 2.1)
  • At least one indexer synced and working
  • Radarr installed (add to your docker-compose.yml like Sonarr)

📖 New Words

  • Quality Profile — Defines acceptable video qualities (720p, 1080p, 4K)
  • Custom Format (CF) — TRaSH scoring system for release attributes
  • Scoring: Positive numbers = prefer, negative numbers = avoid
  • DV/HDR: Dolby Vision / High Dynamic Range (better colors/contrast)

🔧 Lab Steps: Import TRaSH Custom Formats Manually

💡 Note: Lesson 2.3 will teach you to automate this with Recyclarr/Notifiarr. For now, learn the manual process to understand what CFs do.

Add Radarr to Your Stack (If Not Done)

Add to your docker-compose.yml:

  radarr:
    image: linuxserver/radarr:latest
    container_name: radarr
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=America/New_York
    volumes:
      - ./radarr-config:/config
      - /path/to/your/data:/data
    ports:
      - "7878:7878"
    networks:
      - arr-net
    restart: unless-stopped

Run: docker compose up -d

Connect Radarr to Prowlarr like you did with Sonarr.

Open TRaSH Guides Custom Formats Page

Visit: TRaSH Custom Formats Collection

This is THE authoritative list of CFs for Radarr.

Choose a CF to Import (Example: DV HDR10+)

On TRaSH site, find "DV HDR10+" CF → Click "JSON" button → Copy the JSON

Import CF into Radarr

  1. Open Radarr: http://localhost:7878
  2. Settings → Custom Formats → Add Custom Format
  3. Click "Import" button
  4. Paste the JSON you copied
  5. Click "Import"
  6. Click "Save"

You've imported your first Custom Format!

Import More Essential CFs

Repeat step 4 for these CFs (from TRaSH):

  • DV HDR10+ (prefer Dolby Vision)
  • HDR (prefer HDR)
  • BluRay (prefer BluRay source)
  • WEB-DL (allow WEB releases)
  • LQ (avoid low quality)
  • x265 (HD) (prefer efficient codec)

Create a Quality Profile with CF Scoring

In Radarr: Settings → Profiles → Add Profile

  1. Name: "HD-1080p TRaSH"
  2. Allowed Qualities: Check 1080p, 720p, WEB-DL, BluRay
  3. Upgrade Until: Bluray-1080p
  4. Scroll down to Custom Formats section
  5. For each CF, set a score:
    • DV HDR10+: +50
    • HDR: +30
    • BluRay: +20
    • WEB-DL: +10
    • x265 (HD): +5
    • LQ: -100 (avoid!)
  6. Save

Test with Fake Releases

In Radarr: Movies → Add New → Search "Interstellar"

  1. Add the movie, select your "HD-1080p TRaSH" profile
  2. Click "Manual Search" on the movie
  3. Look at the releases — you'll see Custom Format tags!
  4. Releases with higher scores appear first

DO NOT actually download yet — this is just for learning!

Understand the Scoring

Look at a release in the manual search results:

  • Green tags = CFs that matched and added points
  • Total score shown next to release name
  • Higher score = Radarr prefers it for auto-grab

📚 Understanding Quality Profiles vs Custom Formats

Quality Profile:

Defines WHAT qualities are acceptable (720p? 1080p? 4K?)

Example: "I want 1080p minimum, will upgrade to 4K if available"

Custom Formats:

Defines HOW TO SCORE releases within those qualities

Example: "Prefer DV/HDR over SDR, prefer BluRay over WEB-DL, avoid hardcoded subs"

Together:

Quality Profile says "grab 1080p". Custom Formats say "grab the BEST 1080p based on source, codec, and attributes".

🔧 Troubleshooting Decision Tree

Problem: Can't find Custom Formats in Radarr settings

→ Make sure you're using Radarr v3+ (check version in System → Status)
→ Settings → Custom Formats should be visible in sidebar
→ Restart Radarr if just upgraded: docker restart radarr

Problem: JSON import fails with error

→ Copy the FULL JSON from TRaSH (including outer braces)
→ Make sure no extra characters before/after JSON
→ Try manual creation if import fails (less convenient but works)

Problem: No CF tags showing on releases

→ CFs must be added to Quality Profile with scores
→ Release names must match CF regex (e.g., must contain "HDR" to match HDR CF)
→ Check CF conditions in the Custom Format editor

Problem: Radarr still grabs low-quality releases

→ Make sure the Quality Profile is assigned to your movies
→ Check LQ (low quality) CF has NEGATIVE score (e.g., -100)
→ Set minimum Custom Format score in profile if needed
