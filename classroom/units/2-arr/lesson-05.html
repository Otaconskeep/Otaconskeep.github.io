Lesson 2.1: Prowlarr — Start with ONE Indexer

BABY

📚 What You Are Learning

One concept: How Prowlarr acts as a centralized indexer manager for all your ARR apps.

Instead of configuring indexers separately in Sonarr, Radarr, and Lidarr, add them once in Prowlarr and sync everywhere.

✅ You Should Already Have

  • Docker and Docker Compose working (Unit 1)
  • A custom Docker network (from Lesson 1.3)
  • Created /data folder structure on your host

📖 New Words

  • Prowlarr — Indexer manager for ARR apps
  • Indexer — Search service for torrents or Usenet
  • API Key — Authentication token for service-to-service communication
  • Sync Profile: Settings that control which ARR apps get which indexers

🔧 Lab Steps: Install Prowlarr & Sonarr

Create Data Folder Structure

🪟 Windows
🐧 Linux

In WSL2 Ubuntu terminal:

mkdir -p ~/data/{torrents,usenet,media}/{tv,movies,music}
mkdir -p ~/docker/arr-stack
cd ~/docker/arr-stack
mkdir -p /data/{torrents,usenet,media}/{tv,movies,music}
mkdir -p ~/docker/arr-stack
cd ~/docker/arr-stack

Create docker-compose.yml for ARR Stack

version: "3.8"

networks:
  arr-net:
    driver: bridge

services:
  prowlarr:
    image: linuxserver/prowlarr:latest
    container_name: prowlarr
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=America/New_York
    volumes:
      - ./prowlarr-config:/config
    ports:
      - "9696:9696"
    networks:
      - arr-net
    restart: unless-stopped

  sonarr:
    image: linuxserver/sonarr:latest
    container_name: sonarr
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=America/New_York
    volumes:
      - ./sonarr-config:/config
      - /path/to/your/data:/data
    ports:
      - "8989:8989"
    networks:
      - arr-net
    restart: unless-stopped
⚠️ Important: Replace /path/to/your/data with your actual path!
Windows WSL2: Use full path like /home/username/data
Linux: Use /data if you created it at root, or /home/username/data

Fix PUID/PGID for Your User

Find your user ID and group ID:

id

Output example: uid=1000(username) gid=1000(username)

Update the PUID and PGID values in docker-compose.yml if different from 1000.

Start the Stack

docker compose up -d

Wait for containers to start:

docker compose logs -f

Press Ctrl+C when you see "Prowlarr started" and "Sonarr started".

Access Prowlarr Web UI

Open browser: http://localhost:9696 (or http://SERVER-IP:9696)

You'll see the Prowlarr welcome screen!

Add ONE Public Indexer

In Prowlarr UI:

  1. Click Indexers → Add Indexer
  2. Search for "1337x" (a popular public torrent indexer)
  3. Click it → Leave default settings → Click Test
  4. If test passes, click Save

Congratulations! You added your first indexer.

Find Prowlarr's API Key

In Prowlarr: Settings → General → Security

Copy the API Key — you'll need this for Sonarr.

Access Sonarr Web UI

Open browser: http://localhost:8989

Complete the Sonarr setup wizard (accept defaults for now).

Connect Sonarr to Prowlarr

Back in Prowlarr:

  1. Settings → Apps → Add Application → Sonarr
  2. Set:
    - Prowlarr Server: http://localhost:9696
    - Sonarr Server: http://sonarr:8989 (use service name!)
    - API Key: Get from Sonarr → Settings → General
  3. Click Test → Should show green checkmark
  4. Click Save
  5. Click Sync App Indexers

Verify Indexers Synced to Sonarr

In Sonarr: Settings → Indexers

You should see "1337x" listed! Prowlarr synced it automatically.

Test Search in Sonarr

In Sonarr:

  1. Click Series → Add New
  2. Search for a popular show (e.g., "Breaking Bad")
  3. Click the show → DO NOT add it yet
  4. Scroll down → Click Manual Search on any episode
  5. You should see search results from 1337x!

If you see results, indexer integration works!

📚 Understanding Prowlarr's Role

Without Prowlarr (The Old Way):

  • Add 10 indexers in Sonarr manually
  • Add the SAME 10 indexers in Radarr manually
  • Add the SAME 10 indexers in Lidarr manually
  • When an indexer changes URL or goes down, update in 3 places

With Prowlarr (The Modern Way):

  • Add indexers once in Prowlarr
  • Connect ARR apps via API
  • Prowlarr syncs indexers automatically
  • Changes propagate instantly

🔧 Troubleshooting Decision Tree

Problem: Prowlarr or Sonarr not accessible in browser

→ Check containers are running: docker compose ps
→ Check logs: docker compose logs prowlarr
→ Verify port not in use: sudo lsof -i :9696

Problem: "Connection refused" when connecting Sonarr to Prowlarr

→ Use service names, not localhost: http://sonarr:8989 NOT http://localhost:8989
→ Both containers must be on the same Docker network
→ Check: docker network inspect arr-net

Problem: Indexer test fails in Prowlarr

→ Check internet connectivity from container: docker exec prowlarr ping -c 3 1.1.1.1
→ Try a different indexer (some public indexers block certain IPs)
→ Check Prowlarr logs for specific error

Problem: Sonarr search returns no results

→ Verify indexer is enabled in Sonarr → Settings → Indexers
→ Click "Sync App Indexers" in Prowlarr again
→ Test indexer directly in Prowlarr (Search → Manual Search)
