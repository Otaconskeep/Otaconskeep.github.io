Lesson 2.3: TRaSH Automation — Notifiarr vs Recyclarr

ADVANCED

📚 What You Are Learning

One concept: How to automate TRaSH Custom Format syncing so updates flow automatically instead of manual imports.

You'll compare two approaches: GUI-based (Notifiarr/Clonarr) vs config-based (Recyclarr YAML).

✅ You Should Already Have

  • Radarr/Sonarr with manually imported Custom Formats (Lesson 2.2)
  • Understanding of Quality Profiles and CF scoring
  • Comfortable editing YAML files

📖 New Words

  • Recyclarr: CLI tool that syncs TRaSH CFs via YAML config
  • Notifiarr: Web service with GUI for TRaSH CF management
  • Clonarr: Alternative GUI tool for CF syncing
  • Sync Schedule: Automated updates (e.g., daily cron job)

🔧 Lab Steps: Install and Configure Recyclarr

💡 Why Recyclarr in this course? Recyclarr is free, self-hosted, and teaches you infrastructure-as-code. Notifiarr is excellent but requires account signup. Both are valid choices!

Add Recyclarr to docker-compose.yml

  recyclarr:
    image: ghcr.io/recyclarr/recyclarr:latest
    container_name: recyclarr
    user: "1000:1000"
    volumes:
      - ./recyclarr-config:/config
    networks:
      - arr-net
    environment:
      - TZ=America/New_York

Run: docker compose up -d

Create recyclarr.yml Config

Create ./recyclarr-config/recyclarr.yml with:

sonarr:
  tv:
    base_url: http://sonarr:8989
    api_key: YOUR_SONARR_API_KEY_HERE

    quality_profiles:
      - name: HD-1080p
        reset_unmatched_scores:
          enabled: true
        upgrade:
          allowed: true
          until_quality: Bluray-1080p
        quality_sort: top
        qualities:
          - name: Bluray-1080p
          - name: WEB 1080p
          - name: HDTV-1080p

    custom_formats:
      - trash_ids:
          - 496f355514737f7d83bf7aa4d24f8169  # DV HDR10+
          - e23edd2482476e595fb990b12e7c609c  # HDR
          - ed38b889b31be83fda192888e2286d83  # BR-DISK
        quality_profiles:
          - name: HD-1080p
            score: 50

radarr:
  movies:
    base_url: http://radarr:7878
    api_key: YOUR_RADARR_API_KEY_HERE

    quality_profiles:
      - name: HD-1080p TRaSH
        reset_unmatched_scores:
          enabled: true
        upgrade:
          allowed: true
          until_quality: Bluray-1080p

    custom_formats:
      - trash_ids:
          - 496f355514737f7d83bf7aa4d24f8169  # DV HDR10+
          - e23edd2482476e595fb990b12e7c609c  # HDR
          - ed38b889b31be83fda192888e2286d83  # BR-DISK
        quality_profiles:
          - name: HD-1080p TRaSH
            score: 50

Get API keys:

  • Sonarr: Settings → General → API Key
  • Radarr: Settings → General → API Key

Run Recyclarr Sync (Dry Run First)

docker exec -it recyclarr recyclarr sync --preview

This shows what WOULD change without actually modifying Radarr/Sonarr.

Review the output — you should see CFs and scores that will be synced.

Run Actual Sync

docker exec -it recyclarr recyclarr sync

Recyclarr connects to Radarr/Sonarr APIs and updates Custom Formats!

Verify in Radarr/Sonarr

  1. Open Radarr → Settings → Custom Formats
  2. You should see new CFs with [Trash] prefix
  3. Open Settings → Profiles → Your profile
  4. Scroll to Custom Formats — scores should match your config!

Schedule Automatic Syncs

Add a cron job to sync daily:

🐧 Linux
🪟 Windows
crontab -e

Add this line:

0 3 * * * docker exec recyclarr recyclarr sync

This runs daily at 3 AM.

Use Windows Task Scheduler:

  1. Open Task Scheduler
  2. Create Basic Task → Daily at 3 AM
  3. Action: Start a program
  4. Program: wsl
  5. Arguments: docker exec recyclarr recyclarr sync

Update TRaSH IDs When Needed

Get the latest TRaSH IDs from: Recyclarr Wiki

Edit your recyclarr.yml, add/remove trash_ids, then run recyclarr sync.

📚 Recyclarr vs Notifiarr Comparison

Feature Recyclarr Notifiarr
Interface YAML config + CLI Web GUI (point & click)
Hosting Self-hosted Docker Cloud service (free tier)
Setup Complexity Medium (learn YAML) Easy (visual setup)
Version Control Yes (config is code) No (click-based)
Automation Cron/scheduled task Built-in scheduling
Best For Power users, IaC fans Beginners, GUI preference

Bottom line: Both work great. Choose based on your workflow preference.

🔧 Troubleshooting Decision Tree

Problem: Recyclarr "connection refused" to Sonarr/Radarr

→ Use service names: http://sonarr:8989 not http://localhost:8989
→ Verify all containers on same network: docker network inspect arr-net
→ Check API keys are correct (no extra spaces)

Problem: Recyclarr "quality profile not found"

→ Profile name in recyclarr.yml must EXACTLY match name in Radarr/Sonarr
→ Case-sensitive! "HD-1080p" ≠ "hd-1080p"
→ Create the profile in Radarr/Sonarr first if it doesn't exist

Problem: YAML parse errors

→ YAML requires consistent indentation (2 spaces, not tabs)
→ Check for missing colons or dashes
→ Validate at yamllint.com

Problem: Cron job not running

→ Check cron service: systemctl status cron
→ Test command manually first: docker exec recyclarr recyclarr sync
→ Check cron logs: grep CRON /var/log/syslog
