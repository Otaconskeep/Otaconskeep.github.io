🔧 Lab Steps: Install Whisper and Piper

Add Whisper and Piper to docker-compose.yml

In your HA docker-compose directory, add these services:

version: "3.8"

services:
  homeassistant:
    # ... existing HA config ...

  whisper:
    image: rhasspy/wyoming-whisper:latest
    container_name: whisper
    environment:
      - TZ=America/New_York
    command: --model base --language en
    ports:
      - "10300:10300"
    restart: unless-stopped
    volumes:
      - ./whisper-data:/data

  piper:
    image: rhasspy/wyoming-piper:latest
    container_name: piper
    environment:
      - TZ=America/New_York
    command: --voice en_US-lessac-medium
    ports:
      - "10200:10200"
    restart: unless-stopped
    volumes:
      - ./piper-data:/data
💡 Model choices:
Whisper: tiny (fastest), base (good balance), small (more accurate)
Piper: en_US-lessac-medium (natural), en_GB-northern_english_male (British)

Start the Services

docker compose up -d

First run downloads models (may take 2-5 minutes). Watch logs:

docker compose logs -f whisper
docker compose logs -f piper

Wait for "Server started" messages.

Verify Whisper is Running

Check if Whisper Wyoming server responds:

curl http://localhost:10300/info

You should see JSON with model info!

Verify Piper is Running

Check if Piper Wyoming server responds:

curl http://localhost:10200/info

You should see JSON with voice info!

Add Wyoming Integrations in Home Assistant

In HA: Settings → Devices & Services → Add Integration

Add Whisper:

  1. Search "Wyoming"
  2. Host: whisper (service name) OR SERVER-IP
  3. Port: 10300
  4. Click Submit

Add Piper:

  1. Add Integration → Wyoming again
  2. Host: piper OR SERVER-IP
  3. Port: 10200
  4. Click Submit

Test TTS Independently

In HA: Developer Tools → Services

Service: tts.speak

Service Data:

service: tts.speak
target:
  entity_id: tts.piper
data:
  message: "Hello from Piper text to speech"
  media_player_entity_id: media_player.browser

Click "Call Service" → You should hear Piper's voice!

(Note: If no speakers, HA will play in browser media player)

Test STT (Browser Push-to-Talk)

Settings → Voice Assistants → Add Assistant

  1. Name: "Local Voice"
  2. Conversation agent: Home Assistant
  3. Speech-to-text: Whisper
  4. Text-to-speech: Piper
  5. Wake word: None (for now)
  6. Save

Test End-to-End (Browser Assist)

On HA Overview page, click the microphone icon (top right)

Click and hold the button → Say "turn on the bedroom light"

Release → Whisper transcribes → HA executes → Piper responds!

If this works, your voice pipeline is functional!

📚 Understanding Model Choices

Whisper Models (STT Accuracy vs Speed):

Model Accuracy Speed RAM
tiny 🟡 OK 🟢 Very Fast ~1GB
base 🟢 Good 🟢 Fast ~1.5GB
small 🟢 Better 🟡 Medium ~2GB
medium 🟢 Best 🔴 Slow ~5GB

Recommendation: Start with base. Upgrade to small if transcription errors occur.

Piper Voices:

Browse all voices: Piper Voice Samples

Popular choices:

  • en_US-lessac-medium — Natural American female
  • en_US-libritts_r-medium — Clear American voice
  • en_GB-northern_english_male-medium — British male

🔧 Troubleshooting Decision Tree

Problem: Whisper container exits immediately

→ Check logs: docker logs whisper
→ Model download may have failed — delete ./whisper-data and restart
→ Try a different model: --model tiny

Problem: HA can't connect to Wyoming services

→ Use service names if on same Docker network: whisper not localhost
→ If HA uses network_mode: host, use localhost:10300
→ Check port mappings: docker ps

Problem: Push-to-talk doesn't transcribe speech

→ Check browser permissions for microphone access
→ Test microphone: Settings → System → Hardware
→ Check Whisper logs while speaking: docker logs -f whisper

Problem: No audio from Piper

→ Check HA has a media_player entity (browser, speaker, etc.)
→ Try TTS service call with explicit media_player_entity_id
→ Check Piper logs: docker logs -f piper
