🔧 Understanding Each Stage

Stage 1: Wake Word Detection

Microphone listens constantly for a trigger phrase (e.g., "Ok Nabu", "Hey Jarvis").

Why needed: You don't want HA listening to ALL conversation, only after wake word.

HA default wake words: "ok nabu" or custom trained words.

Stage 2: Speech-to-Text (Whisper)

After wake word detected, record audio and send to Whisper.

Whisper converts speech → text: "turn on living room light"

Why Whisper? Fast, accurate, runs 100% local (no cloud APIs).

Stage 3: Intent Recognition (HA Assist)

HA Assist parses the text and decides what to do.

Example: "turn on living room light" → light.turn_on → light.living_room_light

Options: Simple keyword matching OR local LLM for complex commands.

Stage 4: Text-to-Speech (Piper)

HA generates response text: "Turned on living room light"

Piper converts text → audio waveform.

Why Piper? Fast, natural-sounding, runs 100% local.

Stage 5: Speaker Output

Audio sent to speaker (USB speaker, Raspberry Pi, ESPHome device).

You hear the response!

📚 Wyoming Protocol: The Glue

Wyoming is a protocol that lets HA talk to external voice services (Whisper, Piper).

Why Wyoming?

  • Separation of concerns: Run heavy STT/TTS on a different machine (e.g., GPU server)
  • Standardized: Any Wyoming-compatible service works with HA
  • Network-based: Services can run in Docker on same or remote host

🧪 Decision: Hardware for Voice

Option 1: USB Microphone + Speaker on HA Server

Simplest: Plug USB mic/speaker into server running HA

Pros: Easy setup, no extra hardware

Cons: Only works where server is located

Option 2: Raspberry Pi Satellite

Distributed: Pi with mic/speaker in each room, connects to HA over LAN

Pros: Voice in every room, better microphone placement

Cons: Needs Raspberry Pi + accessories

Option 3: ESPHome Device (DIY)

Advanced: ESP32 + I2S microphone + speaker

Pros: Cheapest (~$15), customizable

Cons: Soldering, firmware flashing

💡 For this course: We'll use Option 1 (USB mic on server) for simplicity. You can add satellites later!
