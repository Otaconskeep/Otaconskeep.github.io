🔧 Lab Steps: Complete Capstone Setup

Add openWakeWord Service

Add to your docker-compose.yml:

  openwakeword:
    image: rhasspy/wyoming-openwakeword:latest
    container_name: openwakeword
    environment:
      - TZ=America/New_York
    command: --preload-model ok_nabu
    ports:
      - "10400:10400"
    restart: unless-stopped
    volumes:
      - ./openwakeword-data:/data

Start it: docker compose up -d

Add openWakeWord Integration in HA

Settings → Devices & Services → Add Integration → Wyoming

  1. Host: openwakeword
  2. Port: 10400
  3. Submit

Update Voice Assistant with Wake Word

Settings → Voice Assistants → Edit "Local Voice"

  1. Wake word: Select "ok_nabu"
  2. Save

Configure Audio Input/Output in HA

Settings → System → Hardware

Verify:

  • Microphone detected (USB mic)
  • Speaker detected (USB speaker or audio out)

If not detected, check physical connections and restart HA container.

Test Wake Word (With Internet Still Connected)

Stand near your microphone and say:

"Ok Nabu, what time is it?"

If wake word works, you should hear Piper respond with the current time!

Check HA logs if no response:

docker logs homeassistant -f

Look for "Wake word detected" messages.

Test Voice Command

Say: "Ok Nabu, turn on the bedroom light"

Verify:

  • Light entity changes state in HA
  • Piper responds confirming action

🎓 CAPSTONE TEST: Disconnect Internet

This is the moment of truth!

  1. Physically unplug ethernet cable from your server
    OR turn off Wi-Fi if using wireless
  2. Wait 10 seconds for network to fully disconnect
  3. Verify no internet: Try to ping google.com from terminal (should fail)
  4. Say: "Ok Nabu, turn off the bedroom light"
  5. Listen for Piper's response
  6. Check if light turned off in HA dashboard
✅ SUCCESS CRITERIA:
If the light toggled AND you heard a voice response, you have achieved 100% local voice control!
No cloud services were used. You own this system.

Reconnect Internet and Document Your Success

Plug ethernet back in or re-enable Wi-Fi.

Take a screenshot of your HA dashboard showing:

  • Voice Assistant configured
  • Whisper, Piper, openWakeWord integrations active
  • A light/device that responded to voice command

🔧 Troubleshooting Decision Tree

Problem: Wake word never triggers

→ Check microphone input level in HA System → Hardware
→ Test mic with push-to-talk first (if that fails, mic isn't working)
→ Check openWakeWord logs: docker logs -f openwakeword
→ Try louder/clearer pronunciation of "ok nabu"

Problem: Wake word triggers but no transcription

→ Whisper service may have crashed — check logs
→ Verify Voice Assistant has Whisper selected for STT
→ Speak clearly and wait 1-2 seconds after wake word before command

Problem: Transcription correct but no action

→ Check entity name matches: "bedroom light" must match light.bedroom_light
→ Assign entity to Area if using area-based commands
→ Check HA Assist conversation logs: Settings → Voice Assistants → View transcript

Problem: No audio response (but action executed)

→ Check Piper service running: docker ps | grep piper
→ Verify speaker output device in HA Hardware settings
→ Test speaker with manual TTS service call (Developer Tools)

Problem: Works WITH internet but NOT without

→ Check Voice Assistant NOT using cloud STT/TTS (must be Whisper/Piper)
→ Verify Conversation Agent is "Home Assistant" not a cloud service
→ Check no external integrations required for the device you're controlling
