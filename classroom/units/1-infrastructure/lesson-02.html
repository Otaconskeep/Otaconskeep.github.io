🔧 Lab — one action

Action: Deploy a two-service stack with a named volume and tear it down cleanly.

mkdir -p ~/homelab-academy/class02 && cd ~/homelab-academy/class02
cat > compose.yaml <<'YAML'
name: academy-class02
services:
  web:
    image: nginx:alpine
    ports:
      - "8091:80"
    volumes:
      - ./html:/usr/share/nginx/html:ro
  keep:
    image: alpine:3.20
    command: ["sh","-c","echo class02-ok > /data/hello.txt && sleep infinity"]
    volumes:
      - keepdata:/data
volumes:
  keepdata:
YAML
mkdir -p html
echo '
Homelab Academy Class 02
' > html/index.html
docker compose up -d
curl -s http://127.0.0.1:8091 | head
docker compose exec keep cat /data/hello.txt
docker compose ps
# teardown when evidenced:
# docker compose down

🔧 Troubleshooting decision tree

Port 8091 busy?
└─ Change "8091:80" → free port

Permission error mounting ./html (Windows)?
└─ Keep project under WSL home, not /mnt/c

compose file not found?
└─ Confirm cwd and filename compose.yaml
