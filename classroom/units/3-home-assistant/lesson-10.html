Lesson 3.3: Secure Remote Access — VPN vs Tunnel vs Ports

ADVANCED

📚 What You Are Learning

One concept: How to safely access Home Assistant from outside your home network without exposing it to the internet.

You'll compare three approaches: VPN (best), Cloudflare Tunnel (easy), Port Forward (dangerous).

✅ You Should Already Have

  • Home Assistant running on your local network (Units 3.1-3.2)
  • Basic networking knowledge (IP addresses, ports)
  • Router admin access (for some methods)

📖 New Words

  • VPN (Virtual Private Network) — Encrypted tunnel to your home network
  • Tailscale/ZeroTier: Modern mesh VPN services (easier than traditional VPN)
  • Cloudflare Tunnel: Secure proxy without port forwarding
  • Port Forward: Opening router ports to the internet (risky!)
  • Reverse Proxy: Server that forwards requests to internal services

🔧 Lab Steps: Set Up Tailscale VPN

💡 Why Tailscale? It's free for personal use, works behind NAT, no router config needed, and creates a secure mesh network. Easier than traditional VPN!

Create Tailscale Account

Visit: tailscale.com

Sign up with Google, GitHub, or email (free account).

Install Tailscale on Your Server

🐧 Linux
🪟 Windows WSL2
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up

Follow the link to authenticate your device.

Option 1: Download Tailscale for Windows (recommended)

Option 2: Inside WSL2 Ubuntu:

curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up

Verify Tailscale IP

tailscale ip -4

You'll get a 100.x.x.x IP address. This is your Tailscale internal IP!

Install Tailscale on Your Phone

Download Tailscale app from App Store (iOS) or Play Store (Android).

Sign in with the same account.

Turn on VPN.

Access Home Assistant via Tailscale

On your phone's browser, go to:

http://100.x.x.x:8123

(Use the Tailscale IP from step 3)

You're now securely connected to HA from anywhere!

Test While Away from Home

  1. Turn off Wi-Fi on your phone (use cellular data)
  2. Make sure Tailscale VPN is on
  3. Access HA at the Tailscale IP
  4. Control a light or check a sensor

Success! You're accessing your home network securely.

Enable MagicDNS (Optional)

In Tailscale admin console: Settings → DNS → Enable MagicDNS

Now you can access HA at: http://your-server-name:8123

No need to remember the IP!

📚 Comparing Remote Access Methods

Method Security Ease Router Config
Tailscale/ZeroTier 🟢 Excellent 🟢 Easy None!
Cloudflare Tunnel 🟢 Good 🟡 Medium None
HA Cloud (Nabu Casa) 🟢 Good 🟢 Very Easy None
Wireguard VPN 🟢 Excellent 🔴 Hard Port forward
Direct Port Forward 🔴 Dangerous! 🟢 Easy Port forward
❌ Never port forward HA directly to the internet!
Attackers scan all public IPs for port 8123. Your HA will be found and attacked within hours.

Recommendation:

  1. Best: Tailscale (free, secure, easy)
  2. Also good: ZeroTier or HA Cloud ($6.50/month, supports HA development)
  3. Advanced: Cloudflare Tunnel (free, requires domain)
  4. DIY expert: Self-hosted Wireguard VPN

🔧 Troubleshooting Decision Tree

Problem: Tailscale "failed to connect"

→ Check internet connectivity on server
→ Restart Tailscale: sudo systemctl restart tailscaled
→ Re-authenticate: sudo tailscale up

Problem: Can't access HA on Tailscale IP

→ Verify HA is running: docker ps | grep homeassistant
→ Check correct Tailscale IP: tailscale ip -4
→ Try local IP first to rule out HA issues: http://192.168.1.X:8123

Problem: Tailscale works at home but not on cellular

→ Make sure Tailscale VPN toggle is ON on phone
→ Check phone has internet (try browsing google.com)
→ Restart Tailscale app on phone
