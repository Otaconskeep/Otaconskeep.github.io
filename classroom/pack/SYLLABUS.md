# Syllabus: Homelab Academy

## Expectations

- Complete classes in module order unless the map marks a class as early-optional (Class 15 may run beside 1–3).
- Every class requires: prior-knowledge check, instruction, worked example, guided + independent practice, **Feynman teach-back**, retrieval check, lab, break/fix, mastery gate, reflection.
- “It seems to work” is not evidence. Log command output, test buttons, redacted screenshots, or workbook rows.

## Time

Plan **2–4 hours per class** for first-time builders. Capstone is longer. Total course: roughly **40–60 hours** depending on hardware path.

## Grading / mastery (self-paced)

| Component | Weight (guidance) |
|---|---|
| Feynman teach-backs | Required each class |
| Retrieval checks | Target ≥80% when scored |
| Practical gates | Required each class |
| Stage/module gates | Required to enter next unit |
| Capstone verification matrix | Required for course completion |
| Final reflection | Required |

Unlock rule: **retrieval target + Feynman + independent practice + practical gate + workbook evidence**.

## Policies

- Use only indexers/content you are legally authorized to use.
- Do not expose ARR, download clients, or admin UIs to the public internet.
- Never commit or paste real passwords, API keys, or tunnel tokens into public repos or screenshots.
- Back up before profile migrations, HA upgrades, and remote-access changes.

## Required tools

- Proxmox host **or** Linux VM path via VirtualBox/Type-2 for early classes
- Docker + Compose
- Browser + SSH client
- Optional mic/speaker for voice classes
- GitHub Classroom pack / site workbook templates

## Schedule (suggested)

| Week | Focus |
|---|---|
| 1 | Classes 1–3 + start 15 |
| 2 | Classes 4–5, finish 15 |
| 3 | Classes 6–7 (Gate 2) |
| 4 | Classes 8–10 (Gate 3) |
| 5 | Classes 11–13 (Gate 4) |
| 6 | Class 14 + Capstone + Final reflection |

Weeks 1 through 6 above are the original core path (Modules 1 through 5). The curriculum has since grown to 12 modules. Modules 6 through 12 (Linux Foundations, Network Operations, Docker/Storage/Permissions, ARR Data Model & Compose, Sonarr & Radarr, Download Clients & Indexers, and Requests & Media Servers) continue at the same 2 to 4 hours per class, roughly one module per 1 to 2 weeks pace. Exact topic counts and current class numbering live on the [Modules page](/classroom/modules/), since that list grows as topics are added; this page won't try to re-print a number that goes stale the next time a module gains a topic.

Adjust to your pace; mastery beats calendar.
