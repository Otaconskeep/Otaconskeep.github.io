📖 Complete Technical Glossary

Every technical term used in this course is defined here. When you encounter a highlighted word in a lesson, look it up!

API (Application Programming Interface)
A way for programs to talk to each other. Sonarr's API lets other tools (like Prowlarr or Recyclarr) send requests to add shows or change settings without clicking the web UI.
ARR Stack / *arr Apps
The family of media automation tools: Sonarr (TV), Radarr (movies), Lidarr (music), Readarr (books), Prowlarr (indexer manager). Named for the "arr" suffix in pirate speak.
Bind Mount
A Docker volume that maps a host filesystem path directly into a container. Example: ./config:/config maps the host's ./config folder to /config inside the container.
Container
A running instance of a Docker image. Like a virtual machine but lighter — it shares the host kernel and starts in seconds.
Docker Compose
A tool for defining multi-container Docker applications in a YAML file (docker-compose.yml). Instead of running docker run 10 times, you write one file and docker compose up -d.
Custom Format (CF)
TRaSH Guides scoring system for release quality in Sonarr/Radarr. Examples: prefer DV/HDR, avoid hardcoded subs, require proper groups. CFs assign positive/negative scores to releases.
DHCP (Dynamic Host Configuration Protocol)
The service that automatically assigns IP addresses to devices on your LAN. Your router usually runs the DHCP server.
DNS (Domain Name System)
Translates domain names (google.com) into IP addresses (172.217.14.206). Your router forwards DNS requests to your ISP or a public DNS like 1.1.1.1.
Docker
A platform for running applications in isolated containers. Each container is a lightweight, portable package with its own filesystem and dependencies.
ESPHome
A Home Assistant ecosystem tool for programming ESP32/ESP8266 microcontrollers. Also the protocol used by the new Linux Voice Assistant satellites.
GID (Group ID)
A Linux group identifier number. Docker containers often need PGID=1000 to match your host user's group so file permissions work correctly.
Hardlink
A second directory entry pointing to the same file data on disk. Sonarr/Radarr use hardlinks so completed torrents can stay in the download folder for seeding while also appearing in the media library — without doubling disk usage.
Home Assistant (HA)
Open-source home automation platform that integrates smart devices, creates automations, and runs local voice assistants.
Docker Image
A template/blueprint for a container. Built from a Dockerfile. You docker pull images from Docker Hub, then docker run them to create containers.
Indexer
A search service for torrents or Usenet. Examples: NZBgeek (Usenet), TorrentLeech (private torrent). Prowlarr manages indexers for all your ARR apps.
IP Address
A numerical label for devices on a network. IPv4 example: 192.168.1.100. Your router assigns local IPs to devices via DHCP.
LAN (Local Area Network)
Your home network — the devices connected to your router via ethernet or Wi-Fi. Usually uses private IP ranges like 192.168.x.x or 10.x.x.x.
LLM (Large Language Model)
AI model for understanding and generating text. In Home Assistant Assist, you can use local LLMs to interpret complex voice commands instead of simple keyword matching.
MQTT
A lightweight messaging protocol for IoT devices. Many Zigbee/Z-Wave bridges publish sensor data over MQTT, which Home Assistant subscribes to.
NAS (Network Attached Storage)
A dedicated storage server on your LAN. Examples: Synology, QNAP, TrueNAS. Provides SMB/NFS shares that Docker containers can mount.
NFS (Network File System)
A Linux-native protocol for sharing folders over the network. Faster than SMB for Linux-to-Linux connections.
Piper
A fast, local text-to-speech (TTS) engine built for Home Assistant. Generates voice responses offline. Part of the Wyoming ecosystem.
Port (Network)
A numbered endpoint on a device. Web servers listen on port 80/443, Sonarr on 8989, Radarr on 7878. Format: IP:port like 192.168.1.10:8989.
Prowlarr
An indexer manager for ARR apps. Instead of adding indexers to Sonarr, Radarr, Lidarr separately, add them once in Prowlarr and sync everywhere.
Quality Profile
Settings in Sonarr/Radarr that define which video qualities are acceptable (480p, 720p, 1080p, 4K) and which formats to prefer (DV, HDR, etc.).
Radarr
An ARR app for managing movie libraries. Searches indexers, sends downloads to qBittorrent/SAB, imports files to Plex/Jellyfin.
Reverse Proxy
A server that sits in front of web services and routes traffic. Examples: Nginx Proxy Manager, Traefik. Lets you access services via sonarr.yourdomain.com instead of 192.168.1.10:8989.
SMB (Samba / CIFS)
Windows file sharing protocol. Used by NAS devices to share folders. Mount SMB shares in Linux with mount -t cifs.
Sonarr
An ARR app for managing TV show libraries. Monitors RSS feeds, searches indexers for new episodes, automates downloads.
STT (Speech-to-Text)
Converts spoken words into written text. Whisper is a popular local STT engine for Home Assistant.
TRaSH Guides
Community-maintained documentation for optimal Sonarr/Radarr setup. Covers file structure, hardlinks, Custom Formats, quality profiles. The authoritative ARR playbook.
TTS (Text-to-Speech)
Converts written text into spoken audio. Piper is a fast local TTS engine for Home Assistant responses.
UID (User ID)
A Linux user identifier number. Docker containers often need PUID=1000 to match your host user so files are readable/writable.
VLAN (Virtual LAN)
A way to split one physical network into multiple logical networks. Advanced use: isolate IoT devices from your main LAN for security.
Docker Volume
Persistent storage for Docker containers. Named volumes (sonarr-config:/config) or bind mounts (./data:/data).
VPN (Virtual Private Network)
Encrypted tunnel between your device and a remote server. For homelab: use Tailscale/ZeroTier to access services remotely. For downloads: use Gluetun to route torrent traffic through a VPN provider.
WAN (Wide Area Network)
The outside world / internet beyond your router. Your router's WAN port connects to your ISP modem.
Whisper
OpenAI's speech-to-text model, now available for local use. Fast and accurate STT for Home Assistant voice pipelines. Part of the Wyoming ecosystem.
Wyoming Protocol
A protocol for connecting voice services (Whisper, Piper, wake words) to Home Assistant. Wyoming services can run on separate machines for heavy GPU workloads.
YAML
A human-readable data format used for config files. Docker Compose, Home Assistant automations, and Recyclarr configs are all written in YAML. Indentation matters!
Zigbee
A low-power wireless protocol for smart home devices. Requires a Zigbee hub/coordinator (like Zigbee2MQTT or a USB stick) to connect devices to Home Assistant.
Z-Wave
Another wireless protocol for smart home devices. More expensive than Zigbee but better range and mesh reliability in some setups.
