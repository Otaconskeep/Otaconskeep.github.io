Welcome to Homelab Academy

This is a self-paced technical course, not a wiki. Every lesson teaches ONE concept, shows ONE picture, gives ONE action, and verifies with checkpoints before you continue.

You will build a complete media automation and smart home system from scratch:

  • Docker infrastructure and networking
  • ARR stack (Prowlarr, Sonarr, Radarr) with TRaSH automation
  • Home Assistant automations and integrations
  • Fully local voice assistant (Whisper + Piper)

How This Course Works

Every Lesson Follows the Same Pattern:

  1. Lesson title + difficulty badge
  2. What you are learning (one concept)
  3. You should already have (prerequisites)
  4. New words (linked to glossary)
  5. Architecture picture (ASCII SmartArt diagram)
  6. Lecture videos (optional concept lectures — not embedded)
  7. Steps (with Windows vs Linux callouts when needed)
  8. Checkpoint checkboxes (verify your work)
  9. Continue condition ("If all boxes checked, go to Lesson X.Y")
  10. Troubleshooting decision tree
  11. Exit ticket question
⚠️ Important: Do NOT skip checkpoints. Each lesson builds on the previous one. If you cannot check all boxes, use the troubleshooting tree before continuing.
